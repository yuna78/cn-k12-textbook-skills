> **给谁看**：接手写公众号文章的同学（含 AI 助手）；文末附**可直接粘的家长/老师向文案**。
> **目标**：让家长和老师看完愿意 **star / fork / 下载**这个仓库 ——
> <https://github.com/yuna78/cn-k12-textbook-skills>
> **不要做的事**：改数字、吹效果、写成"替代老师/替代孩子思考"。

---

## 1. 一句话说明这个仓库

> 三个 Agent Skill，把**国家中小学智慧教育平台**的电子课本，变成**孩子自己电脑上、能查、能引用、能打印**的学科知识库。
> 下载 → 拆成带页码的知识 → 只回答有出处的问答。Claude Code / Codex / WorkBuddy 都能跑，MIT 开源。

关键差异（写文章时务必落在这一句上）：

> **它不靠"提示词让它别编"，靠程序卡它**：每条结论都要挂 `[引] 单元 @p页码 :: 逐字原文`，校验不过就 exit 1、拒答。

## 3. 建议的文章骨架（八段）

1. **痛点开场（3 句）**：教材是页图、下不下来、AI 答得像但查不到出处。
2. **我做的东西（1 段 + 05 图）**：三个 skill 串成一条线。
3. **它能干什么（01 图）**：真下下来 11 册，1509 页。
4. **课本怎么变成能查的知识（06 + 02 图）**：页码锚点 `<!-- p.89 -->` 是根。
5. **怎么保证不编（04 + 03 图）**：三道闸门，verify 改一个字就拦下。
6. **用起来是什么样（07 图）**：一条问答走完全程。
7. **踩过的坑（5 条）**：中文 URL 编码、汉字被空格拆断、judge 绝对阈值失准、疑问词污染覆盖率、页码块落 0。
8. **结尾 CTA（见第 5 节）**。

> 标题直接用：**《开源三个 skill，给自家孩子搭了个本地学科知识库》**

## 4. 给家长 / 老师看的卖点（挑 3 条写就够）

- **不用上传**：全部在本地跑，孩子的教材、作业、成绩不出家门。
- **不花钱**：零第三方依赖、不需要 API Key、不用买订阅，一台 Mac 或 Linux 就行。
- **能核对**：AI 说的每句话都能点回"哪本书、第几页、原文哪一句"，家长可以当场翻纸质书对。
- **会拒答**：资料里没有就说没有，不拿常识硬凑——这正是家长最怕的地方。
- **可复用到别的资料**：讲义、答案册、竞赛资料，只要是 PDF 都走同一条流水线。
- **开源可改**：MIT，老师可以改成自己学校的资料库，不用等厂商做功能。

**写给老师的一句**：这套东西的边界写得很清楚——它保证"引文真实存在于原文"，不保证"原文本身是对的"；判断仍然留给人。这句话建议原样保留，老师最认这个。

## 6. 硬规则（违反就不许发）

1. **数字只用仓库里的**：Recall@1 97.4% / 误拒 0% / 拒答准确率 100% / 引用闸门 12/12、1509 页、609 单元、563 图。发稿前重跑 `eval.py` 确认没变。
2. **不许写"AI 帮孩子学习"**：它只做检索与引用，不做讲解替代，也不生成习题答案。
3. **不许暗示能随便下版权内容**：只处理"你有权访问"的资料；图的角标已注明版权归原出版社，仅作技术演示。
4. **不出现真实身份**：孩子的姓名、学校、班级、成绩，一个都不许出现（素材已脱敏，别自己补）。
5. **OCR 的局限要提一句**：扫描件 OCR 会有错字（数学公式、化学上下标尤甚），所以标 `ocr_quality` 并在回答时提示"对纸质书核对"。
6. **公众号平台侧注意**：`06` 图含一页课本原图，属于合理引用；如果平台判版权风险，换用 `02`（只有约 250 字节选）。
