# 知识单元规范（frontmatter 字段）

建库脚本产出的每个单元是一个 markdown 文件，YAML frontmatter 固定下列字段。
下游的问答工具依赖这些字段做检索、页码换算和引用校验，**改名字会导致工具失效**。

| 字段 | 必填 | 含义 | 例子 |
|---|---|---|---|
| `id` | ✅ | 单元唯一标识，也是引用里的 `unit_id` | `人教版九上-第四单元` |
| `title` | ✅ | 单元标题（人类可读） | `第四单元 自然界的水` |
| `subject` | | 学科，用于 `search --subject` 过滤 | `化学` |
| `book` | | 书名，用于多书合库时区分 | `化学 九年级上册` |
| `chapter` | | 章节号/名称 | `第四单元` |
| `source_file` | ✅ | 源 PDF 路径；问答技能的 `page` 命令用它渲染 | `books/化学九上.pdf` |
| `pdf_pages` | ✅ | PDF 物理页范围 | `88-113` 或 `5,9-12` |
| `source_pages` | | **书上印刷页**范围（引用里 `@p` 用的是这个） | `78-103` |
| `tags` | | 主题词，检索加权用 | `[水, 净化]` |
| `ocr_quality` | | `high`/`medium`/`low`；`low` 引用时必须标注 OCR 可能有误 | `high` |
| `updated` | | 生成/更新日期 | `2026-10-26` |

## 正文格式（必须保留页标记）

```markdown
# 第四单元 自然界的水

<!-- p.78 (pdf 88) -->
（该页正文）

<!-- p.79 (pdf 89) -->
（该页正文）
```

`<!-- p.书上页 (pdf 物理页) -->` 这一行是**引用校验的锚点**：

- 问答工具的 `verify` 靠它把「单元 + 页码」落到具体一段文字；
- 删掉页标记后，verify 会报「没有第 N 页」，引用就等于没出处。

> 小技巧：如果一本书没有印刷页码（讲义、自编资料），就用 PDF 页号当 `source_pages`，
> 并在报告里注明「页码为 PDF 页」。

## 页范围写法

`pdf_pages` / `source_pages` 支持 `a-b` 与逗号混排：`3-5,9,12-14`。
检索代码只关心**起点**（用 `pdf_pages` 起点 − `source_pages` 起点 = 固定偏移），
所以**一本书内页码偏移必须一致**；有插页导致偏移不一时，拆成两本书更省事。

## frontmatter 自检

```bash
python3 scripts/build.py --kb kb/ --verify
# exit 3 = 有单元缺必填字段，会列出文件名和缺哪个字段
```
