# 三道闸门的判定口径

三个数决定「能不能答」：

| 指标 | 定义 | 作用 |
|---|---|---|
| **相关度 rel** | `top1 得分 / 该问题理论上能达到的最高分`。分母 = Σ idf(问题实词) × 2.2 | 太低 = 库里根本没这内容 |
| **加权覆盖 cov** | `命中实词的 idf 和 / 问题实词的 idf 和` | 太低 = 只撞上个别通用词，没答到点上 |
| **差距 margin** | `(top1 − top2) / top1` | 太小 = 两个单元都像，不能下结论 |

> **实词** = 在语料词表里出现、且不是疑问/指令词（"什么、怎么、如何、是否、请问、帮我、
> 区别、关系、含义…"）。这样"是什么性质"只按"性质"算覆盖，不会被疑问词拉低。

## 判定矩阵

| rel | cov | margin | 结论 | 允许怎么答 |
|---|---|---|---|---|
| — | — | — | **无**（检索无命中 / rel<22% / 无实词） | 只能说"本地资料没有"；给常识必须标 `⚠️ 非本地资料` |
| ≥22% | <50% | 任意 | **存疑** | 列出候选、逐条给页码，不许只挑一个 |
| ≥22% | ≥50% | <12% | **存疑** | 同上（两个单元都像） |
| ≥22% | ≥50% | ≥12% | **可靠** | 正常答，每条结论配 `[引]`，并跑 verify |

## verify 的硬规则

1. `[引]` 格式必须是 `[引] <unit_id> @p<页码> :: <逐字原文>`，缺字段直接算失败
2. unit 必须存在，页码必须在该单元覆盖范围内
3. 引文去空白/标点后必须是该页原文的**子串**（允许跨行，跨到相邻页会告警但放行）
4. 草稿必须覆盖问题的实词（默认 ≥60%），否则判「答非所问」

exit 1 = 不通过。**判「可靠」但 verify 不过 → 以 verify 为准拒答。**

## 阈值调优的正确顺序

1. 先看检索：`--verbose` 跑 eval，若 `recall_at_1` 低 → 改 chunk 大小/分词，不要动阈值
2. 再看误拒：`false_reject_rate > 0` → 放宽 `rel`（默认 0.22）或把问题里缺失的词补进词表
3. 最后看误答：`reject_accuracy < 1` → 收紧 `cov`（默认 0.5）
4. 每次改完都跑 eval，**验收线**：`recall_at_1 ≥ 0.9`、`false_reject_rate = 0`、
   `reject_accuracy = 1.0`、`citation_gate` 全过

> 阈值是给"这个库多大、多密"定的。换一个完全不同的领域（比如法律条文），
> 前 20 条评估题重新标一遍，再定阈值 —— 别直接套用。
