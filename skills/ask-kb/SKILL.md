# ask-kb — 只回答「有出处」的问题

## 为什么需要它

普通 RAG 的死穴是：检索到了相邻内容，模型就用常识把它"补全"成一个像样的答案。
用户看不出来差别，但拿去复习/做题时会被带偏。所以这个 skill 的三道闸门是**强制的**：

```
① judge  → ② search/get → ③ verify  → 才允许交付
   判能不能答       取原文         硬校验引用
```

## 标准用法

```bash
K="python3 scripts/kb.py --kb kb"

# ① 先判能不能答（可靠 / 存疑 / 无）
$K judge "光合作用的场所是叶绿体吗"

# ② 检索（关键词换 2-3 种说法，效果差别很大）
$K search "光合作用 场所 叶绿体" --top 6
$K get <unit_id>                       # 读单元全文，复制原文
$K cite <unit_id>                      # 拿源文件 + 页码 + 绝对路径

# 图：图号/图题/单元 → 页 → 渲染
$K fig "图12-4-1"
$K page <unit_id> --page 89            # 输出 PNG 路径，可直接给用户看

# ③ 写草稿后硬校验（exit 1 = 不许发）
$K verify draft.md --question "光合作用的场所是叶绿体吗"
```

## 答案格式（照抄）

每个结论后面跟一行引用，**逐字**摘原文（不是复述）：

```markdown
光合作用的场所是叶绿体，叶绿体中的色素能吸收光能。

[引] 生物-九上-第四单元 @p78 :: 光合作用主要在叶绿体中进行
```

- `[引] <unit_id> @p<书上页码> :: <原文>` —— 三个字段少一个 verify 就不认
- 导出的 markdown 里，`unit_id` 用 `kb.py search` 打出来的那个（就是 frontmatter 的 id）
- 引文允许被排版打断（验证时会去掉空白和标点再比），但**字不能改**

## 三道闸门怎么判

见 [references/gates.md](references/gates.md)。速查：

| judge 结果 | 允许的回答方式 |
|---|---|
| **可靠** | 正常答 + 每条 `[引]` + verify 通过 |
| **存疑** | 必须列出多个候选、逐条给页码，不许挑一个当下定论 |
| **无** | 只能答"本地资料没有"，可给常识但**必须标 `⚠️ 非本地资料`** |

**铁律**：`judge` 说可靠、但 `verify` 不通过 → **以 verify 为准，拒答**。
典型场景：问的是这一节，但答案其实在下一节，检索"看起来对"而引文对不上。

## verify 具体查什么

1. 每条 `[引]` 的 unit 是否存在
2. 该 unit 是否真的有这一页（页码在覆盖范围内）
3. **引文是否真的出现在该页原文里**（去空白/标点后严格包含）
4. 草稿是否覆盖了问题的**实词**（疑问词不算），防止答非所问

任何一条不过 → exit 1，逐条打印原因。**不许"差不多"就放行。**

## 调阈值（别乱调低）

```bash
$K judge "..."          # 内置：最高分<4.0 或 实词覆盖<25% → 无；覆盖<50% 或 一二名差<12% → 存疑
$K verify draft.md --question "..." --min-cov 0.6    # 默认 0.6
```

调低阈值等于放水。真要放宽，先跑 `eval.py` 看误答率有没有变差：

```bash
python3 scripts/eval.py --kb kb/ --set eval.json
# 输出 Recall@1 / 误拒率 / 引用闸门通过率
```

评估集长这样（`examples/eval.example.json`）：

```json
[
  {"q": "戊戌变法是什么性质的运动", "expect": ["历史-第一周-1022"]},
  {"q": "汉谟拉比法典用什么文字写成", "expect": ["历史-第一周-1020"]},
  {"q": "这本书讲不讲量子力学", "expect": []}
]
```

`expect: []` 表示**库里应该没有**——用来测"该拒答时是否真拒答"。

## 常见坑

| 症状 | 原因 / 处理 |
|---|---|
| search 一条都不中 | 用词太书面，换成资料里的原词（"场所"→"叶绿体"）；或该内容真没有 |
| judge 说可靠但答不在点上 | 关键词撞上了同一页的其他内容 → 一定要 `get` 读全文再判断 |
| verify 引文对不上 | 引文被"顺手改写"了；回原文复制，别手打 |
| verify 说页码不对 | 页码用了 PDF 页而非书上页；`cite` 会告诉你 `source_pages` |
| 覆盖率总是很低 | 问题里有大量疑问词（已被过滤）；若仍低，说明答案确实没答到问题 |
| 单元 id 带空格/斜杠 | id 由 segment.py 生成，取 `search` 输出里原样的 id |

## 边界

- 这个 skill **不生成知识**，只检索和校验；知识质量取决于 pdf-to-kb 抽得准不准
- OCR 质量 `low` 的单元：引用时要标注「OCR 可能有误，请对纸质书」
- 跨书综合、需要推理的问题：先检索，答不出就明说，别用常识拼
